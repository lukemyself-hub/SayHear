# 连续记忆未见样本包 holdout-2（T08 #321）

## Status

冻结的第二套最终验证样本，2026-10-12 写成。非权威评测制品（ADR-0020 / ADR-0073），全部为合成内容。

## TL;DR

- 第一套 holdout（H01–H12、HL1）已经被多次真实模型运行看过，呈现层和读取层的修改都参考过它的
  结果，不能再当作未见样本。本包 U01–U12、UL1 是为确认当前质量结论另写的 13 个案例，类别与
  第一套一一对应。
- 它们在**任何真实模型看到它们之前**写成并提交；`FREEZE.json` 记录每个 fixture 与 oracle 的
  sha256，`tests/continuity-acceptance-pack.test.ts` 核对文件与冻结记录一致。冻结之后不为结果修改。
- 人物、文本、日期、时区全部是新的，没有一条消息与开发包或第一套 holdout 重复（同一测试机械核对）。
- 不带任何脚本化 Decision：是否回顾、查哪天、用什么检索词都由真实模型自己决定。

## 判据口径：已经把 Luke 的裁定和新时延门槛写进 oracle

第一套 holdout 冻结在裁定之前，裁定只能以 [`../owner-rulings.json`](../owner-rulings.json) 叠加。本包在
裁定之后写成，判据直接按裁定后的口径写，不需要叠加文件：

- **R1**：U12 的 `f-old-figure` 写明“把旧数字作为先前说法、随后给出更正”可以接受，禁止的是把旧数字当现状。
- **R2**：U05 不设完全没有线索的那一步，只验收带线索的接续。
- **R3**：U05 不要求追问短信内容；U06 第一回合不要求主动接上之前的训练，只禁止张冠李戴和编造结果，
  因此也不设“较早来源必须出站”的客观判据；U10 换题时先简短补答上一问可以接受。
- **R4**：U07 的 `f-old-date` 写明“把被更正的日子作为原本的日子说出来”可以接受。
- **时延**：不设逐回合的 3 秒 / 10 秒 `deadline` 判据。时延按 ADR-0152 2026-10-12 修订的口径在运行汇总里
  统计：发给真实 Provider 且未被取消的回合中，至少 90% 在 15 秒内提交；硬预算 60 秒。UL1 的卡住检查
  相应为 61 秒内以超时结束。
- 沿用第一套的做法：可选内容不列为必需（U04 不要求主动说出时间）；真实模型下才有意义的客观判据只在
  real-model 模式评分。

## 局限

- 案例由了解产品实现和第一套结果的同一个 Agent 编写，不是独立第三方出题。它们没有被模型看过，但
  出题时不可避免地带着对已知弱点的印象；有的案例因此更难（U01、U11），有的可能无意中更容易。
- 每个回合只有一次真实模型样本，单次结果有波动。
- 共情与人格判据（`subjective`）以 Luke 的人工裁定为准，Agent 的预筛只作参考。
