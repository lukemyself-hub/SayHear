# AI Impressions Require Cross-Session Evidence

An AI Impression can become a long-term `impression + inferred` Memory Claim
only when at least two independent User Evidence items from two different
Daily Sessions consistently support the same Predicate, typed value, and
scope without a material conflict. Repetition inside one Session, multiple
derived references to the same User Event, and higher model confidence do not
satisfy this gate. Until the gate passes, the proposal remains a
MemoryCandidate.

Predicate Registry evidence policies may require more Evidence, more Sessions,
or a longer time span for higher-risk concepts, but cannot allow a
single-Session Impression to promote. A direct and unambiguous User statement
uses the separate `objective + confirmed` path when long-term admission is
otherwise allowed. This accepts slower or missed Impressions to avoid turning
one conversation or temporary state into a lasting characterization.
