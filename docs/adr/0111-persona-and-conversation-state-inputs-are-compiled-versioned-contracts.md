# Persona and conversation-state inputs are compiled, versioned contracts

Issue #64 asks which modules and versioned contracts own stable personality, current-turn emotional understanding, cross-turn conversation state, and cross-day continuity. The answer keeps the existing Context Compiler and bounded Conversation Agent Harness (ADR-0093 / ADR-0094) as the only owners: every one of these concerns enters the model as a compiled, versioned input. No concern is owned by model memory, framework session state (ADR-0068), or a new intermediate artifact.

**Stable personality** is owned by versioned prompt artifacts rendered by the Context Compiler. The persona artifact is structured in three blocks: the Persona Contract Invariant (identity, relationship, trust, and safety commitments shared by all future Personas), the Canonical Persona self-concept and voice, and operational behavior anchors (Selective Curiosity, Curiosity Stop Signal, Playful Warmth, Conversational Rhythm, Grounded Persona Perspective, Capability-Honest Directness). Locale packs realize tone and language habits per language rather than translating; task instruction differs per GenerationCommand stage. Persona commitments are enforced twice: conversationally in the prompt and mechanically by the behavior contract's hard gates. Persona or locale version resolution failure fails the compile closed — identity never ships absent.

**Current-turn emotional understanding** stays inside the single conversation judgment. The baseline failures (#61) split into per-turn judgment failures (fixable by persona depth, locale packs, task instruction, or model routing) and cross-turn state failures (fixed below); neither requires a pre-generation interpretation step. A separate response-intent or interpretation artifact is rejected for Internal Core: it would double latency and the failure surface and compete with CompiledContext as a second source of truth. The decision is revisitable only on explicit evidence, all three together: (a) the state artifacts and person-level inputs below are shipped and measured; (b) deeper persona/locale/task layers and a model-routing change have been tried against the failing category; (c) a behavior-contract category that structurally requires looking before speaking (情绪命中 or 校准推断) keeps failing in pairwise while trace evidence shows the cause is "didn't look" rather than "didn't know". Any trial happens in Replay/eval first, within the ADR-0093 two-judgment cap; production adoption requires its own ADR.

**Cross-turn conversation state** splits by who can determine it. Deterministic domain projections — Safety Posture (ADR-0112), proactive-follow-up usage, and curiosity-stop release — never pass through the model. Semantic fields requiring understanding are generated asynchronously after each confirmed Event with per-field evidence and confidence: `current_topic`, `emotional_intensity`, `advice_explicitly_requested`, `current_request_requires_focus`, `close_intent`, `user_willing_to_elaborate`. A session-scoped Curiosity Stop Signal projection records suppressed question directions: the model may propose "avoided / refused / topic changed" with evidence, commit is deterministic, and release happens only when the user re-opens the topic or supplies new substantive content; the blanket "stop asking questions" form stays scoped to the current Continuous Exchange.

**Cross-day continuity** is carried by retrieval plus a new standing Person Portrait: a strictly capped, itemized selection of person-describing eligible Claims (Objective Memory plus active AI Impression) compiled into every conversation context, each item carrying its claim version, evidence, and epistemic-kind recall framing, with correction, Forget, contested, and dormant fences applied per item at compile time. The Profile narrative is not compiled into conversation context: it fuses user-stated facts and AI impressions into untraceable confident prose (violating ADR-0009 recall framing), is wholly unavailable during trust-boundary rebuilds, and would become a second source of truth. Profile remains a user-facing artifact only; the knowledge data model (§7.11) is clarified accordingly.

Initial versioned budgets: Person Portrait ≤3 items (≤2 of them AI Impressions), query-retrieved memory ≤2 items, total memory-class injection ≤5 per turn, raw Events 4000 tokens; Rolling Summary thresholds unchanged (12 events / 3,000 tokens). All are versioned defaults to be tuned from retrieval-manifest metrics. Degradation: retrieval failure continues the conversation without memory (recorded as degraded reason); an empty Portrait is silently omitted, never fabricated; a failed safety detector activates no new posture while holding any active one and alerting, with the prompt-layer Minimum High-Risk Response as fallback. A read-only Context Inspector in the Internal Portal (Reflection Inspector pattern) exposes sections, budget versus actual, degradation reasons, retrieval candidates with selection and rejection reasons, DialogueState evidence, Portrait items, and Safety Posture status.
