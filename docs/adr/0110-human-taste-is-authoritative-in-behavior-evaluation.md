# Human Taste Is Authoritative in Behavior Evaluation

> 2026-10-09：[ADR-0152](0152-continuity-requires-history-recall-and-response-acceptance.md)
> 为新连续记忆合同增加小规模真实模型回答验收；共情、人格及语义争议保留人工裁定，
> 不把下述首版例外延用到新能力，也不因此恢复无关的大型评测流程。

> 2026-10-07：[ADR-0150](0150-recent-context-ships-after-deterministic-validation.md)
> 明确近期背景首版不以正式人评为上线门槛，确定性验证后由 Luke 在正常聊天中验收
> 体验。人工味觉裁定仍是权威；下文不应解释为每次近期背景迭代都必须先做盲评。

对话行为的评测里，「被理解感」这类用户可感知质量的最终权威是人工味觉裁定：由唯一
权威评审（Internal Core 阶段即 Internal Owner 本人）在盲评 pairwise 中对六个味觉
维度打分并选出场景最佳。机械检查只承担确定性结构门禁（问题计数、安全资源白名单、
locale 标点卫生）与咨询性预筛，关键词类信号只产出待人工裁定的候选；LLM judge 只
做结构预筛（漏召回、记忆引用越界、跨日时间指向），永不评味觉维度，永不作为发布
证据的最终裁定。

依据是两条实证（#61、#62）：机械关键词检查对中文建议漏报、对英文措辞误报并存，
92% 的反射性提问率靠人工复核转录才发现；五个回应策略在模型自评下毫无差异，同一
批评审的盲评却稳定分出优劣并指出共性缺陷（过度书面语）。这与 ADR-0061 的开发者
判断框架一致：评测是帮助开发判断的方法，不是运行时 Gate。

取舍是评测吞吐受限于单人评审。用只在 pairwise 对比时、只对决策相关场景子集打分
来控制负担；绝对门槛全部由契约判据与硬门禁承担，味觉分数只做相对比较。每条自动
标记都是候选发现，人工核实后才立案；误报与漏报双向记账，台账决定检查层级，超标
即从硬门禁降级为咨询性。
