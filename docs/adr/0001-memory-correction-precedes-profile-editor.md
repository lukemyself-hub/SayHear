# Memory correction precedes the Profile editor

Before any Memory Claim is eligible for future recall, SayHear will support explicit in-conversation Memory Correction and Memory Forget Requests. A full Profile editor remains deferred: this preserves the user's immediate authority over inaccurate or unwanted memory without expanding the first product slice into a general memory-management interface. Affected claims must immediately stop participating in recall; a Memory Forget Request preserves its source Conversation and existing Journal.
