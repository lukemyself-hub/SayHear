# One independently valid relationship per logical Claim

Each person relationship that can independently exist, carry Evidence, have a
time range, or be corrected or forgotten uses its own Predicate and logical
Memory Claim. Colleague and friend can therefore coexist as separate Claims for
the same Entity pair; ending one does not supersede the other. SayHear does not
store an omnibus `relationship_type[]` Claim.

When the same stable relationship changes state or validity, SayHear creates a
new ClaimVersion rather than a new logical Claim. An ended partner Claim may
project the resolver term “ex-partner” without creating a duplicate
`former_partner` fact, while a stable family relationship can remain one
open-ended Claim until correction or counter-evidence appears. This creates
more small Claims and Predicates, but gives every relationship independent
temporal history, Evidence, correction, forgetting, and recall behavior.
