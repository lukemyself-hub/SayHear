# Objective Memory and AI Impression use distinct recall language

SayHear must preserve a Memory Claim's kind and epistemic status in user-facing recall language. Objective Memory may be attributed to what the user previously said, without implying independent verification. AI Impression must use observational and uncertain framing such as “I have an impression...” or “I may be understanding this as...”; it cannot be recalled as “I remember that you are...”.

This makes the boundary between user statements and SayHear's interpretation visible during normal conversation, not only after a user challenges a memory. Recall projection and behavior validation must therefore reject output whose framing upgrades an AI Impression into an Objective Memory or verified fact.
