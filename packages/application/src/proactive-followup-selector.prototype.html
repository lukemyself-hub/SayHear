主动追问原型 · 选谁，以及怎么开口

Throwaway prototype for SayHear#171 · part of the 1A.3b map #163 · 不进产品分支

这一页回答的问题：当 SayHear 可以在你已发起的一段对话里，主动提起一件它记着的事——面对同样合格的一组候选（Open Loop / Memory Claim）——选谁、用什么口气，才让你觉得「被记挂」，而不是被盯着、被打断、被盘问？

怎么用：下面的「引导走查」每个标签是一段设定好的小场景，按顺序按按钮即可；「自由试」里可以随便戳。看不懂某个选择为什么发生时，看「选择过程」一栏。

已定的产品法（四种策略共享，不是比较对象）： 每段 Continuous Exchange 最多主动追问一次，且不设必须追问的配额；只允许问候、开放式开场、自然空档优先（实质话题 / 直接任务是否允许「答完再补一句」正是要测的分歧点）；只使用 active、未过期、非 contested、非 dormant、未被 Forget 的目标；你简短带过、回避、拒绝或转换话题后，该事项立即被抑制——只有你主动重提或新的相关证据才能解除，时间不会自动解除；敏感事项必须措辞温和、允许不回答；紧急 / 高风险永远先于一切主动关心。
脚手架说明：「先接住你当前表达」的那句主回应是固定脚本，不参与比较；比较对象只有「⤷」标出的那句主动关心，或它的缺席。回合类型（问候 / 实质话题 / 任务 / 停止信号……）由页面直接给定——DialogueState 的识别不在本原型问题内。
