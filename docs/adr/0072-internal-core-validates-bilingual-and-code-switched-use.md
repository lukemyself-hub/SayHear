# Internal Core Validates Bilingual and Code-Switched Use

Internal Core 必须验收英文、中文以及两者自然 code-switching 的对话、Journal、
Memory、Predicate mapping 与 Replay 表现。领域对象 ID、Evidence、Entity 和 Claim
不能编码展示语言，新增语言不应要求重构核心数据模型。

当前阶段不在中国大陆上架，也不建设大陆专属部署、合规或 Provider 基础设施。中文
能力是产品与模型质量边界，不等于已经决定大陆地区发布；地区扩张必须另行评估数据
驻留、Provider、网络与监管要求。
