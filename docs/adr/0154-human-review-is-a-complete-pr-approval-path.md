# 人工审查是完整的 PR 审批通路

有限 PR 的端到端测试不能穷尽未来变更。自动系统无法分类或判断专项证据时，曾要求
先更新控制器才能合入。Luke 确认自动审批只加速已有授权范围内的普通变更；人工审查
是独立、完整的正常通路，可以纠正分类、接受证据缺口或承担剩余不确定性。

Luke 对当前被审版本的 GitHub Approve 表达最终决定。控制器继续核验身份、版本、
固定可信 CI、冲突与分支保护，不再要求自动语义分类器同意。新提交或实质需求变化需
重新确认，普通评论及 main 前进本身不撤销批准；与最新 main 的组合必须重新验证。

这个取舍保留人工责任，放弃将所有未来判断编码为硬门禁的做法。控制器更新来自新
流程需求，而不是处理单个例外 PR 的前置条件。缺口不能记为通过，PR 批准也不直接
移除产品运行时围栏或伪造部署结果。具体执行与迁移以最终确认并发布的 SPEC 为准。
