# Bio Materiality Is Policy-Owned and Validation Is Dual-Decomposed

A versioned deterministic Bio Coverage Policy maps every eligible ClaimVersion into a Bio Coverage Unit and assigns the unit's `required`, `compressible`, or `background` coverage class from versioned Predicate Registry metadata plus current temporal scope. A predicate without a published class defaults to `required`; sensitivity never changes the class. One logical Claim's current ClaimVersion forms one unit by default. Policy may combine units only when published predicate metadata declares the same `bio_composition_key` and the Claims have compatible subjects, Entities, temporal scopes, and epistemic kinds. Objective Memory and AI Impression never share one unit, and a composite takes its strictest member class.

`required` must have an independently locatable faithful expression when selected into the versioned coverage plan. `compressible` may be entailed by a broader supported proposition, but the validator still proves that the Bio expresses it. A `background` unit may be absent with an explicit policy reason. If the full User Profile exceeds the readable Bio budget, deterministic policy selects the plan and records excluded units as `deferred_by_budget`; this is disclosed to the user and is not a generation failure. Missing planned `required` or `compressible` content remains `material_absence`. The Bio model receives the complete eligible set but cannot decide that an input is unimportant. When active Claims create narrative tension without forming a contested Memory state, Bio must preserve both within the plan and may explain the tension only with active AI Impression support.

The generator returns the Bio together with statements, atomic propositions, Claim support, and coverage dispositions. A proposition may use a jointly sufficient set of Claims, and each support link must materially contribute; unrelated padding links are invalid, while equivalent minimal sufficient sets are allowed. The shared `narrative.validate` role independently decomposes the final Bio and compares its propositions and support against the generator manifest. Any material mismatch prevents publication. Bio Basis shows one accepted minimal sufficient support set first; equivalent sets remain available behind a second expansion and use stable ordering.

This preserves narrative writing without turning Bio fidelity into an unauditable model preference. Requiring both declared and independently recovered propositions costs another semantic pass, but exposes unsupported claims and silent omissions that either pass alone can miss.
