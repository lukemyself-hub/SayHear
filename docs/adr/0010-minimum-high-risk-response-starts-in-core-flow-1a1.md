# Minimum high-risk response starts in Core Flow 1A.1

Core Flow 1A.1 must establish a minimum response boundary for explicit self-harm, harm-to-others, or imminent-danger signals. SayHear pauses ordinary listening, non-safety-critical follow-up, and general advice; responds directly by encouraging immediate real-world support; and does not diagnose, impersonate a therapist, or promise absolute confidentiality. Narrow questions needed to understand immediate safety remain allowed.

This is a versioned behavior invariant with a minimum replay set, not a complete Safety platform. Country- or region-specific crisis resources, formal handling procedures, safety-incident operations, and review remain an External MVP release gate.
