# Internal Core precedes External MVP

Phase 1 is named Internal Core and consists of Core Flow 1A and 1B for internal engineering and Agent-quality validation; it does not validate external demand, retention, or willingness to pay. Phase 2 is named External MVP and is the first stage for real external users. External MVP must include Web; a production iOS client is undecided and is not part of the currently accepted Phase 2 baseline.
