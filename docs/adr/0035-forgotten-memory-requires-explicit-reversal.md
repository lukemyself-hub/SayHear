# Forgotten Memory requires explicit Reversal

A forgotten Memory Claim or Relationship Qualifier can re-enter long-term
Memory only after an explicit user Memory Forget Reversal. Natural repetition,
elapsed time, model confidence, Consolidation, and repair never lift the
Forget fence or trigger a permission prompt. Ordinary later mentions may still
support the current response and Journal, but cannot promote a long-term
MemoryCandidate. When the target is uniquely resolved, the same final or
corrected User Event serves as both Reversal authorization and new Evidence,
creating a new ClaimVersion immediately; there is no permission-only
intermediate state. Old Evidence exclusions, ClaimVersions, projections,
Embeddings, and Profile state remain ineligible. This deliberately simple rule
may treat “remember that again” as renewed confirmation, but prevents ordinary
conversation or background work from silently undoing a user trust decision.
