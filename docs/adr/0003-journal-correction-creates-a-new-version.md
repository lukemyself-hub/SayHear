# Journal correction creates a new version

Users cannot freely edit a Journal or casually regenerate it for arbitrary style variants, preserving the Journal as SayHear's third-person observation rather than user-authored text. When a user identifies a factual error or an unsupported inference presented as fact, SayHear will correct the source and publish a new Journal Version that supersedes the previous one. The original is no longer the current product record.

ADR-0097 supersedes only this ADR's blanket ban on user-requested regeneration: a
policy-governed Derived Artifact Regeneration Action may create one validated
superseding JournalVersion from current valid sources, without adding free-form editing,
custom style control, candidate approval, or continuous rerolls.
