# Journal observations preserve uncertainty

A Journal may include SayHear's subjective interpretation when it has sufficient underlying user evidence, even if the user did not state that interpretation directly. The prose should naturally preserve the distinction between observation and confirmed fact when appropriate, and the statement must retain Evidence links internally. Unsupported interpretation or inference written as fact is a diagnostic concern, not an opaque publication veto; the publication boundary is defined by ADR-0107.
