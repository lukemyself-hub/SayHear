# Memory source explanations are conversational and evidence-backed

SayHear will not add a dedicated citation or memory-source interface by default. When a user asks why SayHear remembers or believes something, SayHear must answer in the conversation using the selected Memory Claim's valid Evidence: relevant dates and user expressions, plus whether the Claim is Objective Memory or an AI Impression. If the Evidence cannot be expanded to a valid User Event Revision, SayHear must say it cannot verify the source rather than generate a plausible explanation.

This keeps the normal experience natural while making memory correction and user control understandable. It requires every recallable Memory Claim to retain typed Evidence and source lineage from its first eligible version; Journal, Reflection, Profile, and the model's own prior responses cannot serve as substitute proof.
