# Entity clarification follows semantic impact, not data completeness

SayHear does not ask the user to resolve an identity merely because an EntityMention is unbound. It asks one natural clarification only when the ambiguity would materially change its understanding of the user's experience or thoughts, the current response, the meaning of a Journal, or the attribution of future Memory. If the user does not answer, avoids the question, refuses, or changes topic, SayHear stops asking, keeps the Mention unbound, and responds or writes only at the level supported by existing Evidence.

A unique high-confidence identity may be reused. A clearly introduced new person, place, or project creates a user-scoped unresolved Entity, but a pronoun, multiple plausible candidates, or another unclear reference remains only an unresolved EntityMention. Entity binding, promotion, merge, or split requires an explicit user statement, stable repeated Evidence, or a user correction; a shared name is never sufficient.

This deliberately tolerates unresolved Mentions and duplicate Entities so an incorrect identity link cannot contaminate long-term Memory. Missing identity resolution may reduce continuity temporarily, while false continuity can corrupt later empathy, Journal interpretation, and recall.
