# Bio Narrative Identity Is Explicit and Locale-Frozen

The narrative artifact is named `Bio`, and its immutable version is `BioVersion`; `User Profile` remains the distinct Objective Memory plus active AI Impression source model. Bio uses the current Self Entity canonical label as the person's display name and only uses a pronoun the user has explicitly declared. It never infers gender or pronouns from a name, language, or remembered experience; when no declared pronoun exists, the writer repeats the name or rewrites the sentence. Each Bio GenerationCommand freezes one presentation locale, the Self Entity version, display label, and optional declared pronoun together with the Claim set. The Bio is generated and validated in that locale, while Bio Basis quotations preserve the user's original language. A locale change uses an ordinary Bio rebuild and does not create a trust-boundary invalidation.

This keeps narrative identity tied to the existing Self Entity instead of creating Bio-owned identity state. One validated locale per BioVersion also prevents an unvalidated read-time translation from becoming the text the user sees.
