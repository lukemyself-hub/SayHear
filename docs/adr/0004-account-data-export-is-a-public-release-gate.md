# Account data export is a public-release gate

Internal Core does not require Account Data Export. Before External MVP handles real user data, SayHear will provide a low-prominence, asynchronous Account Data Export containing Conversation, Journal, Profile, and Memory data, while Journal Export remains the only prominent content-export experience. This preserves the Journal-first product hierarchy while allowing users to take their underlying account data with them.
