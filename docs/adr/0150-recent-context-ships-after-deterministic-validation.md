# 近期对话背景通过确定性验证后上线，体验在正常聊天中验收

> 2026-10-09：下文保留七天背景首版的历史取舍。
> [ADR-0152](0152-continuity-requires-history-recall-and-response-acceptance.md)已为新的
> 连续记忆体验合同增加实际模型回答的上线前验收，不可继续援引本例外跳过新能力的
> 时间、话题覆盖、自然接续和人格验证。既有确定性安全检查仍适用。

Luke 在 [#290](https://github.com/lukemyself-hub/SayHear/issues/290) 确认：先交付
[ADR-0149](0149-recent-conversation-context-is-bounded-source-history.md) 的近期连续性，
Reflection Registry 窄合同独立交付，框架实测留待后续决定。旧研究的 9–15 工程人日
无法可靠换算 Coding Agent 的时间或用户精力，不作为预算、交付承诺或停止门槛。
按合理技术范围和复杂度拆分迭代，完整执行 SPEC 在 [#291](https://github.com/lukemyself-hub/SayHear/issues/291) 收敛。

首版在现有 PostgreSQL 与 Context Compiler 内完成七天有界原文读取、必要相邻
Assistant 上下文、来源选择与日期/角色标记、明确关联的旧消息排除、冻结和调用前
有效性检查；Inspector 展示实际注入、遗漏、排除和失败原因。不新增模型摘要流水线、
自主历史查询循环、框架状态真源或新的来源级用户控制体系。具体读取上限和 token
预算为版本化实现策略，用合成案例校准；不以工程量估算替代技术判断。

上线前用固定合成数据真实走“昨日写入 → 今日新 Daily Session → 实际冻结 Context”，
并验证 Provider Egress 实际使用的来源边界。覆盖双语/code-switch、七天日期边界、
跨午夜/DST、长对话、多次经历、异步抽取失败、Correction、Forget/Reversal、owner、
revision、Data Epoch、Purge 和编译后调用前的并发失效。符合已冻结选择策略的来源
必须入选，明确应排除的来源不得进入 Context 或出站；预算取舍案例预先声明预期，
不能事后放宽预期掩盖核心连续性案例漏读。用户控制只验证 ADR-0149 接受的明确
来源关联合同，不暗中要求识别所有同义表达或新增普通经历 Forget 能力。

这些确定性检查全部通过，并完成适用的发布基线与专项验证后，可上线。不设第二层
真实 Provider 回复的人评、盲评偏好或自然度发布门槛；也不以模型自评替代被取消的
人评。Luke 上线后通过正常聊天与真实经历验收体验，私人聊天不复制为正式测试、
评测或框架样本。该取舍接受“来源正确进入 Context”不能证明模型一定自然承接的
限制；实际承接、歧义、编造、多余追问与延迟/token 用量通过上线后观察继续改进。
本决定仅修订本次近期背景迭代的上线门槛，不取消其他能力的确定性安全合同。

确认跨 owner/epoch、明确应排除来源仍被发送、Purge 后内容复活或其他确定性硬失败，
立即关闭新增近期背景路径，恢复原对话路径。回退保留用户控制记录与必要迁移，
不得解除 Forget 或复活旧 Evidence，也不牵动独立的 Episode/Reflection 能力。
读取失败或超时放弃本轮新增背景，继续依据当前有效输入回应；不复用未经重验的
旧背景。体验缺陷记录后迭代，明显影响正常聊天时可以单独关闭新增路径。

发布与 [SPEC #275](https://github.com/lukemyself-hub/SayHear/issues/275) 协调，采用固定
基线加受影响专项验证，不增加无关完整 G1 重验。实施时必须核实 #275 的机制与 ADR
修订是否落地；本决定不把已发布 SPEC 当作已实现，也不豁免仍生效的运行时授权、
部署身份、权限、删除恢复与数据围栏。相关发布依赖单独列明，不把整套发布改造
并入近期修复。生产不执行 Full Purge 或备份恢复演练。

本决定对 ADR-0110 的关系是：保留人工味觉裁定的权威，但本次不把人工味觉评测
设为上线前必经步骤；不以历史 1A.3a/1A.3b 的 blind pairwise 条款追加本次人评。
ADR-0138 的合成验收、ADR-0141 的 G1-only、ADR-0144 的隔离环境与生产身份边界
继续适用，通用发布机制修订仍由 #275 承载。

这是已确认的设计与验收决定，不是运行代码、测试通过、发布或部署证据。
