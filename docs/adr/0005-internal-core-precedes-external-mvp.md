# Internal Core precedes External MVP

Phase 1 is named Internal Core and consists of Core Flow 1A and 1B for internal engineering and Agent-quality validation; it does not validate external demand, retention, or willingness to pay. Phase 2 is named External MVP and is the first stage for real external users. External MVP must include Web. Its production iOS scope was later resolved by ADR-0062: External MVP launches on Web before iOS.
