# One relationship fact has one canonical Claim

One person-relationship fact uses one canonical logical Memory Claim. A
directed Relationship Predicate defines its canonical subject and object
roles, so inverse phrasing and the opposite person's view reuse the same Claim;
a symmetric Predicate normalizes the Entity pair so Mention order cannot create
a duplicate. The Predicate Registry also owns localized forward, inverse, and
symmetric role projections. Evidence, temporal changes, Correction, and Forget
apply to the canonical Claim and invalidate every projection together. This
adds Registry metadata, Entity-pair normalization, and projection logic, but
avoids duplicated Evidence, diverging temporal states, repeated Recall, and
one-sided correction or forgetting of the same relationship fact.
