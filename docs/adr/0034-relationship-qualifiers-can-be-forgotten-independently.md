# Relationship Qualifiers can be forgotten independently

A Memory Forget Request may target either a whole Memory Claim or one
Relationship Qualifier. Qualifier-level Forget immediately removes that role
from every direction and locale projection without asserting that the role was
false. The base relationship may retain a neutral projection only when User
Evidence outside the Forget scope independently supports it; if the forgotten
expression was also the relationship's only Evidence, the whole Claim stops
recall. The original Conversation and Journal remain, while a durable
Memory-scoped Evidence exclusion prevents Extraction, Consolidation, or repair
from relearning the forgotten content. Ambiguous scope is clarified
once before Memory changes. This adds scoped eligibility fences, but provides
fine-grained user control without bypassing intent through a weaker derived
memory.
