# Explicit User Statements Create Confirmed Objective Memory

A single direct and unambiguous User statement is sufficient to create an
`objective + confirmed` Memory Claim once the separate long-term admission
checks pass; SayHear does not require repetition. `confirmed` means the User
explicitly made the statement, not that SayHear independently verified the
outside-world fact. Registry policy, temporal and business scope, Entity
resolution, Evidence validity, one-off state filtering, and any Forget fence
still decide whether the statement belongs in long-term Memory.

An understanding that the User did not directly state, but SayHear derived
from one or more expressions, can only become an `impression + inferred`
Claim. Raw expressions remain Evidence and unresolved proposals remain
MemoryCandidates; neither needs an `observed` Claim state. `contested` is
reserved for an existing Claim or Relationship Qualifier that encounters
conflicting Evidence. Removing `observed` avoids a gray path that could make
model inference look like Objective Memory.
