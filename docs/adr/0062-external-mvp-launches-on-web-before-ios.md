# External MVP Launches on Web Before iOS

Phase 2 External MVP 首发仅提供 Web；正式 iOS 客户端不属于该阶段范围。Web 已能验证
用户是否愿意持续表达、是否感到被理解，以及 Journal 与 Memory 是否形成长期价值，
因此先完成这轮验证，再引入 iOS，避免同时扩大客户端、音频权限、分发与跨端交付范围。

iOS 仍是长期日常使用的主要平台。这个决定明确接受 Web 可能低估移动使用意愿、通知
召回与移动 Voice Live 价值的限制；Web 结果不能被解释为已经验证或否定这些移动端
假设。
